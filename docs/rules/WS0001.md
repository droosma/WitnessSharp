# WS0001: Prefer `[LoggerMessage]` for `IWitness<T>` extension method logging

**Category**: Performance | **Severity**: Info | **Enabled**: Yes

## Cause

Direct `ILogger` calls in `IWitness<T>` extension methods allocate and parse message templates at runtime. Use `[LoggerMessage]` to eliminate both (automatic on **net9.0+** via source-generator interceptor; manual on **net8.0**).

```csharp
public static void LogOrderPlaced(this IWitness<OrderService> witness, int orderId)
    => witness.Logger.LogInformation("Order {OrderId} placed", orderId); // ⚠️ WS0001
```

## How to Fix

**net9.0+**: Automatic—no action needed (source-generator interceptor optimizes calls).

**net8.0**: Apply the code-fix or manually refactor:

```csharp
public static partial class OrderServiceLog
{
    [LoggerMessage(Level = LogLevel.Information, Message = "Order {OrderId} placed")]
    static partial void LogOrderPlacedCore(ILogger logger, int orderId);

    public static void LogOrderPlaced(this IWitness<OrderService> witness, int orderId) =>
        LogOrderPlacedCore(witness.Logger, orderId);
}
```

To suppress in performance-insensitive code:

```csharp
#pragma warning disable WS0001
witness.Logger.LogInformation("Non-critical: {Value}", value);
#pragma warning restore WS0001
```
