# WS0001: Prefer `[LoggerMessage]` for `IWitness<T>` extension method logging

**Rule ID**: WS0001 | **Category**: Performance | **Severity**: Info (suggestion) | **Enabled**: Yes

## Cause

Extension methods on `IWitness<T>` that call `ILogger` methods (`LogTrace`, `LogDebug`, `LogInformation`, `LogWarning`, `LogError`, `LogCritical`, or `Log`) with constant message templates box value-type arguments and parse templates on every call. The `[LoggerMessage]` pattern eliminates both costs via allocation-free, strongly-typed logging. On **net9.0+**, a source-generator interceptor rewrites these sites automatically; on **net8.0**, apply the code fix.

```csharp
public static void LogOrderPlaced(this IWitness<OrderService> witness, int orderId)
{
    witness.Logger.LogInformation("Order {OrderId} placed", orderId); // WS0001
}
```

## How to Fix Violations

Apply the **"Convert to [LoggerMessage] pattern"** code fix, or rewrite manually by extracting the logging call into a partial static method:

```csharp
public static partial class OrderServiceLog
{
    [LoggerMessage(Level = LogLevel.Information, Message = "Order {OrderId} placed")]
    static partial void LogOrderPlacedCore(ILogger logger, int orderId);

    public static void LogOrderPlaced(this IWitness<OrderService> witness, int orderId) =>
        LogOrderPlacedCore(witness.Logger, orderId);
}
```

Suppress the warning for rare, performance-insensitive logging (e.g., startup diagnostics):

```csharp
#pragma warning disable WS0001
witness.Logger.LogInformation("One-off startup message {Value}", value);
#pragma warning restore WS0001
```
